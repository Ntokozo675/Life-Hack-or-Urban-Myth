# Life Hack or Urban Myth
life hack or urban myth
# Description- what does the app do
The app assists users test their knowledge of popular life hacks by deciding if each given hack is a genuine life hack or an urban myth
# What does the app consist of 
The app has a welcome screen that shows a welcome message and provides a start button 
# Quiz Screen
It shows the life hack statements and lets the user decide if it is Hack(true) or Myth(false)
# Instant Feedback 
Tells the user whether their answer is incorrect or correct, there after it provides an explanation 
# The next button 
this allows the user to move to the next hack statement 
# Score Screen 
Displays the users' total score and provides a personalised feedback 
# Play Again 
Allows the users to restart the quiz 
# Colour Scheme
I used black and white to create a modern clean interface and turquoise to add a pop of colour
# What did I use to make the app 
Kotlin
Android studio
Jetpack Compose 
Github
# The application flow 
The application starts with a welcome screen where the user can press start to begin with the quiz.
The user gets a hack statement with 2 options to choose from Hack(True) or Myth(False)
The application provides feedback and has a next button to move to the next statement
After all the questions have been answered the user receives the overall score
And gets the option to play the quiz again
